Computer Architecture & Memory Guide

Ինչպես է համակարգիչը հասկանում Տեքստը և Հիշողությունը

Սիմվոլներից, բացատներից (space) ու նոր տողերից մինչև RAM-ում փոփոխականների զբաղեցրած տեղը։

01

Ամեն ինչի հիմքը․ Երկուական համակարգ (0 և 1)

Համակարգչի պրոցեսորը (CPU) և հիշողությունը (RAM) կազմված են միլիարդավոր փոքրիկ էլեկտրոնային անջատիչներից՝ տրանզիստորներից։ Դրանք կարող են լինել միայն 2 վիճակում.

Անջատված է
0
Էլեկտրական լարում չկա (0 Volts)
Միացված է
1
Էլեկտրական լարում կա (+3.3V / +1.2V)
  • 1 Bit (Բիթ): Ամենափոքր ինֆորմացիոն միավորն է (ընդունում է 0 կամ 1 արժեքը)։
  • 1 Byte (Բայթ) = 8 Bit: 1 բայթով կարելի է կոդավորել 28 = 256 տարբեր արժեքներ (0-ից մինչև 255):
02

Տեքստ, Սիմվոլներ, ASCII և Unicode (UTF-8)

Համակարգիչը տառեր չի հասկանում, նա ճանաչում է միայն թվեր։ Ուստի ամեն մի տառի, սիմվոլի կամ բացատի (space) տրված է կոնկրետ թվային կոդ։

⚡ Ինտերակտիվ Սիմուլյատոր

Գրեք ցանկացած տեքստ (հայերեն, լատինատառ, սիմվոլներ `#&$+*`, space կամ enter) և տեսեք, թե ինչպես է համակարգիչը դա տեսնում.

Սիմվոլներ 0
Ծավալը RAM-ում 0 Bytes
Սիմվոլ Անվանում / Տեսակ Dec (Թիվ) Hex (16-ական) Binary (2-ական) Ծավալ
03

Ինչպես է հասկանում Սիմվոլները, Space-ը և Newline-ը

# & $ + _ ( ) @ * : " ' ? ! /

Այս բոլոր հատուկ սիմվոլները ASCII աղյուսակի ստանդարտ մաս են կազմում։ Համակարգչի համար սրանք սովորական 1 բայթանոց թվային կոդեր են (օրինակ՝ #-ը 35 է, @-ը 64 է)։

Պրաբել ( Space )

Բացատը համակարգչի համար "դատարկություն" չէ, այլ իրական սիմվոլ։ ASCII-ում դրա կոդն է 32 (երկուական՝ 00100000)։ Այն զբաղեցնում է ճիշտ այնքան տեղ, որքան օրինակ 'A' տառը։

Նոր տող գնալը ( Enter )

Երբ սեղմում եք Enter, ֆայլի մեջ ավելանում է անտեսանելի կառավարող սիմվոլ․

  • Linux / macOS: \n (Line Feed - 10, 1 Byte)
  • Windows: \r\n (Carriage Return + Line Feed - 13 ու 10, 2 Bytes)
04

Ինչքա՞ն տեղ է գրավում Փոփոխականը RAM-ում

Երբ ծրագրում ստեղծում եք փոփոխական, համակարգիչը օպերատիվ հիշողության (RAM) մեջ հատկացնում է հստակ չափի հասցեավորված բջիջներ։

🧠 RAM Հիշողության Մոդելավորում

Սեղմեք տվյալների տեսակների վրա՝ տեսնելու համար, թե ինչպես են դրանք տեղաբաշխվում RAM-ում.

Տվյալի Տեսակ Ծավալը RAM-ում Նկարագրություն / Արժեքների միջակայք
Boolean 1 Byte (8 bits) Պահում է true (1) կամ false (0)։ (Տեսականորեն 1 բիթ է, բայց RAM-ում հասցեավորման նվազագույն չափը 1 բայթն է)։
Integer (32-bit) 4 Bytes (32 bits) Ամբողջ թվեր -2,147,483,648-ից մինչև +2,147,483,647:
Float / Double 4 - 8 Bytes Կոտորակային/կետով թվեր (օրինակ՝ 3.14159) IEEE 754 ստանդարտով։
Char (ASCII) 1 Byte Մեկ անգլերեն տառ, թիվ կամ սիմվոլ։
Char (Unicode / UTF-16) 2 Bytes Մեկ հայերեն, ռուսերեն կամ այլ լեզվի տառ։
String (Տեքստ) Տառերի քանակ × Չափ + Overhead Դինամիկ հիշողություն (Heap): Անգլերեն սիմվոլը 1 բայթ, հայերեն տառը UTF-8-ում 2 բայթ + ցուցիչ (pointer) և տեքստի երկարության ինֆորմացիա (8-16 բայթ):
